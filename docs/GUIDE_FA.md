# راهنمای فارسی اجرای StockFlow

## نسخه اول چه چیزی دارد؟

این پروژه یک نمونه عملیاتی چندصنعتی با چهار شرکت ساختگی است: فروشگاه اینترنتی، عمده‌فروشی مواد غذایی، قطعات خودرو و لوازم اداری. اطلاعات، قیمت‌ها و فروش‌ها کاملاً آزمایشی هستند.

**قابلیت‌ها:** ثبت ورود و خروج، فروش، انتقال بین دو انبار، رزرو موجودی، سفارش تأمین‌کننده، دریافت بخشی از سفارش، گزارش فروش روزانه، هشدار موجودی و نمایش داشبورد.

## اجرای بدون Docker

۱. ZIP را استخراج کنید و Terminal را داخل پوشه اصلی پروژه باز کنید.

۲. برای ایجاد دیتابیس آزمایشی این دستور را اجرا کنید:

    python3 -m stockflow.cli seed

۳. برای مشاهده گزارش نمونه:

    python3 -m stockflow.cli demo --org online-retail

۴. برای فهرست پیشنهادهای سفارش مجدد:

    python3 -m stockflow.cli reorder --org auto-parts

۵. برای اجرای تست‌ها:

    python3 -m unittest discover -s tests -v

## داشبورد تحت وب

برای راه‌اندازی داشبورد از دو دستور زیر استفاده کنید:

    python3 -m pip install -r requirements-api.txt
    python3 -m uvicorn stockflow.api:app --host 127.0.0.1 --port 8000

سپس آدرس http://127.0.0.1:8000/dashboard را در مرورگر باز کنید. می‌توانید چهار شرکت را از منوی بالای داشبورد انتخاب کنید. مستندات API نیز در http://127.0.0.1:8000/docs قابل مشاهده است.

## ورود داده CSV

قالب فایل در samples/movements_template.csv قرار دارد. برای واردکردن آن:

    python3 -m stockflow.cli import-csv --org online-retail --file samples/movements_template.csv

هر ردیف باید یک event_key منحصربه‌فرد داشته باشد تا اجرای دوباره همان فایل منجر به ثبت دوباره موجودی نشود. اگر یک ردیف اشتباه باشد، کل فایل برگشت داده می‌شود.

## مرحله بعد پروژه

بعد از اینکه نسخه پایه را روی سیستم خودتان اجرا و تست کردید، اتصال PostgreSQL، Docker و n8n، سپس گزارش روزانه خودکار و تأیید سفارش خرید را اضافه می‌کنیم.

این نسخه برای آزمایش و نمونه‌کار است، نه محیط عملیاتی شرکت واقعی. در API هنوز احراز هویت و مدیریت سطح دسترسی وجود ندارد؛ آن را فقط به‌صورت محلی اجرا کنید.
